# LeetCode Solutions

This repository is for collecting LeetCode problems and solutions in one place.

## Structure

- `problems/` - one folder per problem
- `notes/` - optional study notes, patterns, and reminders
- `templates/` - reusable solution templates

## Suggested naming

- Use a folder name like `001-two-sum/`
- Keep a `README.md` in each problem folder with the problem statement summary
- Add solution files like `solution.py`, `solution.ts`, or `solution.cpp`

## Example

```text
problems/
  001-two-sum/
    README.md
    solution.py
  020-valid-parentheses/
    README.md
    solution.py
```

## Quick start

1. Add a new problem folder under `problems/`
2. Put your solution in that folder
3. Commit and push to GitHub
